# Skills used
Loaded (Skill tool) before the relevant step: `cms:trigger-efficiency`, `cms:awkward-array`, `cms:hist`, `af-fnal-lpc:lpc-condor`. Not loaded: `cms:hepdata`, `vector-awkward` (not needed), `standalone-script` (scripts use the provided LCG env instead of uv), `cms:cmssw`.

- **trigger-efficiency** (followed): reference-trigger method, Clopper-Pearson, plateau rule (target 0.99, min_events 100), several references, per-era path check. I used `turnon.py` (`efficiency`, `find_threshold`, `plateau`, `plot_turnon`) directly on counts accumulated over files; worked as documented. Gaps: `list_hlt_paths.py` is for NanoAOD ROOT; our inputs are Parquet so I wrote my own listing (`scripts/hltlist.py`). The skill's advice (HT800 absent in 2016H) was confirmed. It gives no guidance on 2-D (j0,j1) turn-ons or on choosing the OR for boosted-jet analyses; I did that myself. Its demo/threshold example is dijet m_jj; the variable choice here (leading-jet pT) is mine.
- **awkward-array**: skim is flat Parquet with fixed j0/j1 columns, so jagged awkward operations were not needed; I used numpy/pyarrow. Skill not applicable beyond the reminder to read only needed columns and cast float32 weights to float64. The skill says nothing on Parquet row-group streaming, which I needed for memory (5 workers × full columns exhausted 11 GB).
- **hist**: followed the weighted-histogram / xsec×lumi/sumw conventions and CMS label (`hep.cms.label("Private work", data=...)`, lumi, com). I used `np.histogram` with weights and weights², not `hist.Hist`, because I needed explicit Σw² for ABCD error propagation. Correct, but a snippet for propagating errors through ratios of weighted histograms would help.
- **lpc-condor**: followed job.sh/job.jdl templates, one test job, then all 224 jobs (all returned 0, 15.6 GB to EOS scratch). Worked. `make_filelist.py` was not used (I wrote jobs.txt from inputs/skim_files). Missing from the skill: the interactive tool foreground limit (~2 min) and the fact that `pkill -f`/`pgrep -f` patterns match the invoking shell's own command line (killed my shell twice); and that local multiprocessing runs launched without `setsid nohup` die with the tool call. Also `PYTHONPATH=dir python` clobbers the LCG PYTHONPATH (use `export PYTHONPATH=dir:$PYTHONPATH`) — worth a gotcha line.
- Nothing in the skills covered ABCD design, independence tests, closure, or blinding; all of that is my own design.
