**Title:** `feat(background-est): add abcd skill with EXO-17-021 validation`

**Body** (fill in `.github/pull_request_template.md`; adapt headings to it):

```markdown
## Summary

Adds the `background-est` plugin with the `abcd` skill (ABCD/matrix estimate of
a data-driven QCD multijet background) and `validation/abcd/`, which tests it
on the m_avg spectrum of boosted paired dijets in 2016 G+H JetHT Open Data
(16.3 fb-1) against the boosted ABCD of CMS EXO-17-021 (arXiv:1808.03124,
HEPData ins1685989).

## Validation

Two blind Sonnet students got the same prompt and skim, one with the skill and
one without. An Opus validator compared both with EXO-17-021.

|                         | with skill                       | without skill              |
| ----------------------- | -------------------------------- | -------------------------- |
| ABCD axes               | mass asymmetry x deta (CMS pair) | N2 x N2                    |
| TF                      | quadratic in m_avg, applied to C | per bin                    |
| Method validity         | consistent                       | tension                    |
| Pred vs obs (unblinded) | chi2 2.2/14                      | chi2 9.3/17                |
| Shape vs CMS            | tension (chi2 27.2/11)           | inconsistent (chi2 202/14) |
| Method choices vs CMS   | consistent                       | inconsistent               |

Remaining skill gaps (fitted-TF helper, over-coverage check, fail-band width,
sigmoid TF, signal contamination, substructure preselection) are listed in
`validation/abcd/README.md`.

Caveats: CMS Open Data, private work, not CMS results. 16.3 fb-1, PUPPI vs CHS
tau21 (4.7x per-jet efficiency), soft-drop vs pruned mass, an unexplained
factor ~1.9 in yield for a CMS-like selection, one run per arm.
```
