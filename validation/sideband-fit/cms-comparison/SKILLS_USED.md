# Skills used in the independent review

The archived sideband-fit skill defines a sideband-normalized binned Poisson fit, valid integer input, integrated predictions, masked model selection and distinct interval targets. Its helper accepted the recovered published counts with nulls in the excluded bins. Replacing every null with a billion events left all serialized fit outputs identical. The rules separating observed counts from expected background were essential for interpreting the published-data check.

The hist skill's variable-bin storage and mplhep plotting reference guided the displayed errors, units, CMS typography and ratio panels. The Open Data label applies to the educational analysis. The separately sourced CMS Figure 1 data are marked published.

The repository's cms-results-validator agent provided the independent-source and comparability workflow. A useful addition for rounded HEPData tables is to propagate the displayed precision of both bin edges and the value through the count reconstruction. A second addition is to state explicitly which of the post-selection intervals condition on the selected order.
