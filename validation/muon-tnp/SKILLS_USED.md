# Skills used in the muon-tnp validation

Run on cmslpc, November 2026. Python: LCG_109 view (Python 3.13.11, numpy 2.2.6, uproot 5.6.0, awkward 2.8.9,
iminuit 2.31.1, correctionlib 2.6.4, mplhep 0.4.1). Condor workers used the same view. Data subset: every 5th file of
Run2016G/H SingleMuon (user's speed request); all 28 DY MC files.
